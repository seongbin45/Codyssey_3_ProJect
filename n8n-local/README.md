# n8n-local/ — 로컬 실험용 n8n 트리 (커밋 제외)

초기 설치·실험에 쓰인 **보조 로컬 디렉터리**다.  
본 실행 환경은 주로 `../n8n-runtime/` 을 쓰고, 이 폴더도 **gitignore** 대상이다.

| 항목 | 내용 |
|------|------|
| 목적 | 설치 실험, 패키지 스모크 테스트 등 |
| 커밋 | ❌ 저장소 미포함 |
| 제출 산출물 | 여기가 아니라 `../n8n/*.workflow.json` |

## 관련 경로

| 경로 | 설명 |
|------|------|
| `../n8n-runtime/` | 주 로컬 런타임 |
| `../n8n/` | Git에 올리는 워크플로·문서 |
| `../.gitignore` | `n8n-local/` 제외 |
