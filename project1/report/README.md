## 유지 규칙

### 상대 경로가 가리키는 위치

이 폴더(`project1/report/`) 기준으로 보고서 본문의 미디어 링크는 **한 단계 위(`../`)가 `project1/`** 이다.

| 보고서 안 경로 예 | 실제 위치 |
|------------------|-----------|
| `../gif/make_high_1_form.gif` | `project1/gif/…` |
| `../n8n/n8n_workflow_view.png` | `project1/n8n/…` |
| `../make/Make_workflow_view.jpeg` | `project1/make/…` |
| `../n8n/n8n_png/n8n_setup_or_oauth.gif` | `project1/n8n/n8n_png/…` |

- `gif/`, `make/`, `n8n/` 을 **다른 폴더로 옮기면**, 위 표와 같이 보고서 본문의 `![…](../…)` 링크를 **새 상대 경로에 맞게 전부** 수정한다.  
  (예: 다시 저장소 루트로 빼면 `../../gif/…` 처럼 깊이가 바뀐다.)
- 민감정보(이메일, 시트/폼 ID, API 키)는 본문·캡처 모두 마스킹한다.
- 상태·TODO는 보고서 상단과 §9를 갱신한다.
