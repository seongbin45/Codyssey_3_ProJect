촬영일: **2026-07-25**. 보고서 임베드는 영문 별칭 폴더 `../make_gif/n8n_*.gif` 를 사용한다.

| 항목 | 내용 |
|------|------|
| 목적 | 원본 파일명·타임스탬프 보존, 검수 추적 |
| 구성 | 분기 3종 × (폼 응답 1 + 에이전트 액션 1) = 6 GIF |
| 해상도 | 1920×1080 |
| 주의 | **원본 파일명(고액/일반/기타) ≠ 실제 분기** (아래 매핑 필수) |

## 내용 기준 매핑 (프레임 검수 확정)

원본 한글 이름을 바꾸지 않는다. 보고서·제출용 복사는 `make_gif/` 영문 별칭으로 한다.

| 실제 분기 | 입력 메모 (7/25) | 결과 탭 | 원본 (이 폴더) | 보고서용 (`../make_gif/`) |
|-----------|------------------|---------|----------------|---------------------------|
| 고액 | `테스트 노트북 200000원` | 고액 지출 분류 결과 | `고액_지출_1_…` / `고액_지출_2_…` | `n8n_high_1_form.gif` / `n8n_high_2_action.gif` |
| 일반 | `마트에서 식용유 5800원` | 일반 지출 분류 결과 | **`기타_지출_1_…`** / **`일반_지출_2_…`** | `n8n_normal_1_form.gif` / `n8n_normal_2_action.gif` |
| 검토(미분류) | `분류 잘 모르겠음 -5000` | 검토 필요 | **`일반_지출_1_…`** / **`기타_지출_2_…`** | `n8n_review_1_form.gif` / `n8n_review_2_action.gif` |
