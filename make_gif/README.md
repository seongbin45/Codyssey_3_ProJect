# make_gif/ — 실행 증명 GIF (보고서용 영문 별칭)

비교 분석 보고서(`../report/프로젝트1_자동화_도구_비교_분석_보고서.md`)가 **직접 링크**하는 실행 데모 GIF 모음이다.  
파일명은 도구·분기·단계가 드러나도록 영문으로 통일했다.

| 항목 | 내용 |
|------|------|
| 목적 | Make·n8n 각 분기(고액/일반/미분류)의 **폼 제출 + 워크플로 액션** 화면 증명 |
| 해상도 | 대체로 1920×1080 |
| 명명 규칙 | `{도구}_{분기}_{단계}.gif` |
| 원본(n8n 한글명) | 형제 폴더 `../n8n_gif/` (파일명≠실제 분기 주의) |

## 명명 규칙

| 토큰 | 의미 |
|------|------|
| `make` / `n8n` | 도구 A / 도구 B |
| `high` | 고액 분기 (`amount ≥ 50000`) |
| `normal` | 일반 분기 (`amount < 50000` ∧ 분류 가능) |
| `review` | 미분류·검토 분기 (`amount = 0` ∧ `Classification = 분류불가`) |
| `1_form` | Google 폼 입력·제출 + 응답 시트 반영 |
| `2_action` | 자동화 실행(캔버스/로그) + 결과 시트 탭 확인 |
