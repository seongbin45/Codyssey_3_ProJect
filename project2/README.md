# project2/ — 프로젝트 2: 자유 주제 자동화

Codyssey 미션 **[프로젝트 2] 자유 주제 자동화 설계 및 구현**.  
프로젝트 1(`../make/`, `../n8n/`, `../report/`)과 **폴더로만 구분**하고, 브랜치는 나누지 않는다 (`main` 유지).

| 항목 | 내용 |
|------|------|
| 상태 | **주제 후보 정리 완료 · 확정 대기** (추천: 후보 1) |
| 도구 | **1개 선정** (프로젝트 1과 달리 단일 도구) |
| 공통 구조 | Trigger 1+ · Action 2+ · 조건 분기 1+ · **각 분기 1회 이상 실행 증거** |
| 자동 실행 | Trigger 발생 시 **자동** 실행 (설계 문서만 제출 불가) |

## 1. 미션 산출물 체크리스트 (프로젝트 2)

| # | 요구 | 상태 |
|---|------|------|
| 1 | 자동화할 **반복 업무 1개** 정의 | ⬜ 주제 확정 후 |
| 2 | **도구 1개** 선정 + 선정 이유 | ⬜ |
| 3 | 워크플로우 **설계 문서** (설명 또는 다이어그램) | ⬜ |
| 4 | **구현 화면** 캡처 | ⬜ |
| 5 | **실행 결과** 캡처 (분기별 1회 이상 권장) | ⬜ |
| 6 | 실제 동작 워크플로우 (Export/Blueprint 등) | ⬜ |

### 공통 기능 요구 (프로젝트 1과 동일 코어)

- Trigger ≥ 1  
- Action ≥ 2  
- 조건 분기(Filter/Router) ≥ 1 → **분기 경로마다 1회 이상 실행 확인**  
- (권장) 보너스1: 생성형 AI Action — 분류·요약에 자연스럽게 붙일 수 있음  
- (선택) 보너스2: 실패 알림·재시도

## 2. 주제 후보 (Trigger · Action · 분기 포함)

| # | 주제 | Trigger | Action | 조건 분기 | 비고 |
|---|------|---------|--------|-----------|------|
| **1** | **팀 문의/피드백 자동 분류** (FinFit 실사용) | 문의 폼 또는 이메일 수신 | OpenAI로 긴급도·카테고리 분류 → Sheets 기록 | 긴급 / 일반 — **긴급만** Slack·Discord 알림 | 미션 취지「진짜 반복 업무」에 가장 부합 · **추천** |
| 2 | **RSS/뉴스 피드 요약 알림** | RSS 새 글 감지 | OpenAI 요약 + 키워드 매칭 → Sheets 아카이브 | 관심 키워드 **유/무** — 매칭 시 Slack, 아니면 시트만 | 계정 장벽 낮음 · 구현 단순 |
| 3 | **캘린더 일정 리마인더** | Google Calendar 새 이벤트 | 일정 유형 파싱 → Sheets 로그 | 오늘 / 이번주 / 그 이후 — **임박만** 별도 알림 | 개인 Gmail·Calendar만으로 가능 |

> 위 표 외 **직접 아이디어**도 가능. 확정 시 이 절 상단에 **선정 주제**를 한 줄로 고정하고 나머지는 참고로 남긴다.

### 추천 방향 (작성 시점)

**후보 1 (팀 문의/피드백 자동 분류)** 을 1순위로 권한다.

| 이유 | 설명 |
|------|------|
| 미션 정합 | “매일 반복되는 실무”에 가깝고, 프로젝트 1(지출 분류)과 **AI 분류 → 분기 → 시트/알림** 패턴을 재사용할 수 있음 |
| 보너스1 | OpenAI 분류가 본 흐름의 핵심 Action이 되어 보너스 AI 연동이 자연스러움 |
| 도구 후보 | 프로젝트 1 경험상 **Make**(빠른 폼·Slack) 또는 **n8n**(이미 셀프호스트) 중 택 1 — 선정 이유를 짧게 쓰면 됨 |
| 리스크 | Slack/Discord 연동·알림 채널 권한. 없으면 **이메일 알림** 또는 **긴급 탭만 분리**로 완화 |

후보 2·3은 진입은 쉽지만 “팀 실무” 스토리가 약해 채점 서술에서 차별화가 덜할 수 있다.
